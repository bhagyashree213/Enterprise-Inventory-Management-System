# Enterprise Inventory Management System

## Features
- Role-based authentication
- Secure login system
- Inventory management
- Order tracking
- Supplier management
- Reports dashboard
- Audit logs

## Tech Stack
- ASP.NET MVC
- C#
- SQL Server
- HTML/CSS/JavaScript

## Setup
1. Clone repository
2. Configure SQL Server connection string
3. Run database scripts
4. Start application
